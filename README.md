# Logician

Logician is a web app that takes an argument and checks whether the conclusion actually follows from the premises.

You can paste in a piece of text or a URL. It tries to break the argument down into its premises and conclusion, translates the reasoning into formal logic, and then checks whether the argument is logically valid. It also looks for a few common logical fallacies.

Live demo: https://logic-police.onrender.com

## Why I built this

I started thinking about this because I read a lot of opinion pieces, posts, and arguments online where something sounds convincing at first, but doesn't necessarily hold up when you actually break it down.

I wanted to build something that could take an argument and reduce it to its basic structure: what are the claims being made, what is the conclusion, and does the conclusion actually follow from those claims?

Instead of just saying that an argument "sounds right," Logician tries to give you a more concrete answer using formal logic.

One thing I also wanted to be careful about is the difference between a valid argument and a persuasive one. A lot of arguments in the real world are inductive, so their conclusions might be reasonable or likely without being logically guaranteed. Logician doesn't treat those two things as the same.

## What it does

### Extract

The app takes a block of text and tries to identify the individual claims, including which statement is the main conclusion and which statements are being used as premises.

### Formalize

It converts the argument into propositional logic. For example:

`P1 >> P2`

represents "if P1, then P2."

The formalization step is rule-based rather than generated by an AI model, so the same input should produce the same result.

### Validate

Once the argument has been formalized, Logician uses SymPy to check whether there is a possible situation where all of the premises are true but the conclusion is false.

If such a situation exists, the argument is invalid. If no such situation exists, the argument is valid.

### Check for fallacies

There is also a simple fallacy detector that looks for patterns associated with common informal fallacies such as ad hominem, straw man, and slippery slope.

This part is intentionally fairly simple, so it shouldn't be treated as a complete fallacy detector.

### Fetch from a URL

You can also give the app a URL and it will try to extract the article text and analyze it.

## What it works well with

Logician works best when the text actually contains a reasonably clear argument.

For example:

> All humans are mortal.
> Socrates is human.
> Therefore, Socrates is mortal.

It can also work with things like:

* Opinion pieces with a clear argument
* Editorials
* Structured debates
* Short arguments with identifiable premises and conclusions
* Arguments where the reasoning needs to be separated from how persuasive it sounds

## Current limitations

There are definitely cases where it doesn't work very well.

It struggles with:

* Personal essays and narratives
* Text with lots of quotations
* Very short posts where there isn't enough context
* Paywalled articles
* Arguments where the conclusion is implied rather than stated
* Writing that isn't really making an argument in the first place

For example, if you give it a Substack post that is mostly someone's personal story, there may not be much for it to analyze. The system can still try to extract an argument, but the result may be noisy.

That's one of the limitations I'm aware of rather than something I want to pretend the tool has completely solved.

## How it works

At a high level, the process looks like this:

1. Extract the text
2. Split it into individual statements
3. Identify premises and the conclusion
4. Translate the statements into propositional logic
5. Use SymPy to test the logical validity
6. Run the fallacy checks
7. Return the results

The project is still a work in progress, and there are a lot of things I'd like to improve, especially the argument extraction and formalization parts.
